FOUND. — connect emails and the orders sheet

1. Create a Google Sheet (name it FOUND Orders).
2. In that sheet: Extensions > Apps Script.
3. Delete any default code. Paste everything from Code.gs.
4. At the top of Code.gs, fill in:
   - OWNER_EMAIL   the address that receives new order alerts
   - BRAND         name, tagline, city, contact email, phone, website, Instagram
   - BANK          the real bank account details (must match js/config.js)
5. Optional: to put a logo in the emails, upload the logo to Google Drive,
   share it as "Anyone with the link", and paste the file id into BRAND.logoFileId.
   Leave it blank to use the FOUND. wordmark instead.
6. Run the function sendTestEmails once from the editor. It sends both emails
   to your own address so you can check how they look before going live.
7. Deploy > New deployment > type: Web app
   Execute as: Me
   Who has access: Anyone
8. Authorise the script (Gmail + Sheets + Drive if you set a logo).
9. Copy the Web App URL.
10. Paste that URL into js/config.js as orderWebhook.
11. Put the real bank account details in js/config.js as well.

Until step 10 is done, orders still save in the browser only and no emails or
sheet rows are sent.

To preview the email design without deploying, open these files in a browser:
   preview-customer-email.html
   preview-owner-email.html
They are samples only. The live emails are built by Code.gs.
